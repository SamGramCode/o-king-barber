# O-King Barber - Sistema de Reservas

Sistema completo de reservas, administración y e-commerce para la barbería O-King Barber en Santiago, Chile.

## 📋 Características

### Frontend (Landing Page)
- ✅ Video de presentación con fondo
- ✅ Navegación transparente con letras blancas
- ✅ Logo circular superpuesto en borde del video
- ✅ Sección de "Barberos Profesionales" con fotos
- ✅ Divisor con patrón de peine
- ✅ Sección de servicios
- ✅ Ubicación con Google Maps en tiempo real
- ✅ Sistema de agendamiento multi-paso

### Sistema de Agendamiento
- Seleccionar barbero → Fecha → Hora → Registrar datos
- Datos capturados: nombre, WhatsApp, fecha nacimiento
- Seguimiento en Instagram/TikTok para redención de souvenirs

### Admin Panel
- 📊 Dashboard con estadísticas
- 📅 Gestión de citas
- 💈 Gestión de barberos
- 🔧 Gestión de servicios
- 🛍️ Gestión de productos
- 🎁 Promociones (cumpleaños, cantidad, suscripción)
- 👥 Gestión de clientes
- 🏆 Gestión de souvenirs

## 🚀 Próximos pasos

1. Ir a Supabase y crear proyecto
2. Ejecutar el SQL en `supabase.sql`
3. Actualizar credenciales en `index.html`
4. Conectar repositorio a Vercel
5. Deploy automático en cada push
